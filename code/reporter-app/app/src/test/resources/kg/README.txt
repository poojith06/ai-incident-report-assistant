scenarios.json is the contract test between the seed pack's normalization rules (app/src/main/assets/kg/seed_pack.json) and the Kotlin adapter/engine. It holds the 12 required scenarios of spec section 16 in order. Each entry has the saved `report` (English values as the app produces them), the `expected` normalization, the exact `incident` (ValidatedIncident JSON; urgency is null and locationText is the report's place text) the adapter must produce from that report, `mustInclude` (recommendation ids that must be shown to the REPORTER; every phase stays within the output limits, so ranking does not matter), `mustNotShowReporter`/`adminOnlyPresent` (DRAFT recommendations visible only in the admin preview), optional `optionalDependents` (shown recommendations with a DEPENDS_ON prerequisite; not required), `mustIncludeArrangements` and `suppressedArrangements` (temporary arrangements shown / suppressed for lack of campus facts) and `historyDependent` (recommendations that need recurrence history). The file is generated by tools/kg_seed/build_seed_pack.py, which computes the incident with a Python mirror of the normalization semantics; do not edit it by hand.
